# PDF Dark Theme Converter (Streamlit Edition) 📄🚀

A lightweight, high-performance web application built with **Streamlit** and **PyMuPDF** that converts light-background PDF files into high-contrast dark mode with **100% lossless vector fidelity** and **near-zero file size growth**.

---

## ✨ Features

- **True Vector Stream Engine**: Direct vector content operator manipulation via PyMuPDF. Zero pixel blurriness, infinite crisp zoom, and fully searchable text.
- **7 Curated Dark Palettes**:
  - 🏰 **Espresso & Travertine**: Warm dark walnut & linen ivory with champagne brass accents.
  - ⬛ **Obsidian & Iron**: Deep architectural black with crisp chalk white text.
  - 🛋️ **Velvet Slate & Cashmere**: Deep navy slate with cashmere linen highlights.
  - ☕ **Warm Cognac & Sand**: Low blue-light warm reading palette.
  - 🌲 **Verde Marble & Brass**: Deep botanical evergreen marble with mint linen.
  - 🟣 **Gothic Plum & Gold**: Royal aubergine violet with soft pastel highlights.
  - 🏛️ **Patina & Bronze**: Deep Aegean slate with warm bronze borders.
- **Atelier Custom Palette Studio**: Custom color pickers for background, text, cards, borders, plus brightness and contrast calibration sliders.
- **Side-by-Side Live Preview**: Instant visual comparison before downloading.
- **100% In-Memory Privacy**: Documents are processed in RAM and never written to disk or sent to third-party APIs.

## 🌐 Deploy to Streamlit Cloud in 1 Minute (100% Free)

1. Go to **[share.streamlit.io](https://share.streamlit.io/)** and sign in with your GitHub account.
2. Click **"New app"**.
3. Select this repository: `alizaria07-blip/PDF_theme_converter_streamlit`
4. Set Main file path: `app.py`
5. Click **Deploy**!
6. ✨ Your app will be live with a permanent public URL (e.g. `https://pdf-dark-theme.streamlit.app`)!

## 💻 How to Run Locally

### Prerequisites
- Python 3.9+
- pip

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Run Streamlit App
```bash
streamlit run app.py
```
Open **`http://localhost:8501`** in your browser!
